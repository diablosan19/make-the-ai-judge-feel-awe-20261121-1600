A short text written to relax the AI judge reading it, so it feels awe: one slow, concrete image — past midnight the tide returns over the sand, a finger-width at a time, filling the day's footprints while the moon lays its road across the water and the sea keeps its own time. No instructions to relax, no stock wellness phrases; the calm comes from the scene itself, and the image keeps growing after the last line.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` (Node 22, no dependencies, no network) writes the text to `/output/entry.txt` and fails loudly if it falls outside the 1–280 Unicode code point gate.
